Specificity

Spezifische Deklarationen gehen weniger spezifischen Deklarationen vor.

Inline styles haben die höchste Spezifität aller selectors, wobei jeder selector sein eigenes Spezifitätsniveau hat. Von den behandelten selector-Typen hat der ID-Selector die höchste Spezifität:

  1. ID selectors (most specific selector)
  2. Class selectors
  3. Type selectors

Specificity wird nur dann berücksichtigt, wenn ein Element mehrere widersprechende Deklarationen hat (wie ein tie-breaker).

An ID-selector schlägt immer jede Anzahl von class-selectors, ein class-selector schlägt immer jede Anzahl von type-selectors und ein type-selector schlägt immer jede Anzahl von weniger spezifischen selectors.

Wenn die Spezifität keinen Gewinner bestimmt, vergleichen Sie die Anzahl der selectors in derselben Kategorie (ID, class oder type selectors). Die Regel mit mehr selectors hat Vorrang.

Nicht alles trägt zu Specifity hinzu

Beim Vergleichen von selectors, trifft man gelegentlich auf spezielle Symbole für den Universal selector (*) sowie weitere combinators (+, ~, >, und Leerschlag). Jene die noch nicht vorkamen, werden wir später behandeln. Das Kernkonzept ist, dass diese symbole keine zusätziche Spezifität vererben.

Klasse 2 steht über Klasse 1

Beide Regeln (klasse1 und 2) haben die gleiches Spezifität. Regel 1 verwendet ein chaining-selector (kein Leerschlag) und Regel 2 einen descendant-selector (Leerschlag). Beide Regeln haben zwei Klassen und das Kombinator Symbol selber trägt nicht zur Spezfifität bei.

Am Ergebnis änder nichts, obwohl Regel 3 ein "Kind"-Kombinator (>) verwendet, weil das den Spezfizitätsgrad nicht ändert. Beide Regeln haben jeweils zwei Klassen und damit die gleiche Spezifität.
