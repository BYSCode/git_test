DESCENDANT-COMBINATOR (Leerzeichen)

Der Descendant-Kombinator wählt Elemente aus, die irgendwo verschachtelt innerhalb eines anderen Elements liegen - egal auf welcher Ebene (Kind, Enkel, Urenkel, etc.). Er wird eifach durch ein Leerzeichen zwischen zwei Selektoren ausgedrückt.

Ein Beispiel:

Direkt in der Karte

  • Tiefer verschachtelt

Ausserhalb der Karte

.karte p (mit Leerzeichen) trifft auf jedes p, das sich irgendwo INNERHALB eines Elements MIT KLASSE "karte" befindet - egal wie tief. Im Beispiel werden also beide inneren Absätze grün: sowohl der direkte Nachfahre als auch der p innerhalb von "li" innerhalb von ul. Der letzte Absatz - p "Ausserhalb der Karte" bleibt unverändert, weil er ausserhalb von .karte liegt. - Hier gilt also: Alle p in der class=Karte = grün.

MERKREGEL

A B (mit Leerzeichen) bedeutet: "style jedes B, das irgendwo innerhalb von A liegt" Die Reihenfolge ist wichtig: links steht der Vorfahre, rechts der Nachfahre.
